# bellavero-site

Landing page da Bellavero (massageador de ventosa), publicada na Netlify em https://bellavero.netlify.app.

- `index.html` — página de vendas (preço, link do checkout Yampi e Pixel no bloco `CONFIG` e no topo)
- `politicas.html` — privacidade, termos, trocas e entrega
- `anim-*.mp4` / `uso-costas.webp` — animações da página
- `ads/` — vídeos dos anúncios (links públicos para a Meta)

Cada push na branch `main` é publicado automaticamente pela Netlify.
